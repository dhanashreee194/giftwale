# Giftwale

Enquiry-led gifting storefront for Giftwale — Creating Memories.

There is no payment gateway. Shoppers build an enquiry list, send their details, and Giftwale confirms the order by phone, WhatsApp or email.

## Live site

GitHub Pages: https://dhanashreee194.github.io/giftwale/

## Run locally

```bash
npm install
npm run dev
```
